Chapter 1 - Python, NumPy & Digital Image Fundamentals:   

Introduces the basic concepts required to work with digital images using Python. 
It explains how images are represented as numerical arrays and introduces essential Python, NumPy, Matplotlib, and OpenCV operations. 
Students learn how to read, display, inspect, crop, resize, modify, and save images, as well as understand RGB/BGR channels, grayscale images,
pixel coordinates, data types, bit depth, normalization, sampling, and quantization. This chapter provides the foundation needed for the image-processing and 
computer-vision techniques covered in later chapters.
